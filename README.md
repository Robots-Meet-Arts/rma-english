# Robots Meet Arts – English Resources

**When Robots and Humanities Encounter**

This repository contains all English resources from the Robots Meet Arts Erasmus+ project.

---

## About the Project

Robots Meet Arts brings robotics and coding into humanities classrooms for primary school teachers. The activities invite children to imagine, create, and express themselves: robots become characters in stories, dancers in choreographies, explorers of ancient civilisations, messengers between languages.
